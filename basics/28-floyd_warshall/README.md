# Floyd-Warshall - ワーシャルフロイド法

## 概要
ワーシャルフロイド法は、**すべての頂点ペア間の最短距離** を一度に求めるアルゴリズムです。「頂点 0..k だけを中継点として使ってよいとき、i から j への最短距離」を k を1つずつ増やしながら更新する動的計画法（DP）で、三重ループだけで書けます。負の辺にも対応し、負閉路があれば `dist[i][i] < 0` になります。

## 目的
- 頂点数が小さい（V ≤ 数百）グラフで、任意の2点間の距離を何度も問われる問題を一発で解く
- 「到達可能か」の推移閉包（`bool` 版）にもそのまま使える
- DP の「中継点を1つずつ増やす」考え方を身につける

## ワーシャルフロイド法の動き
サンプルグラフ（有向）：
```
辺:  0→1 (3)  0→3 (7)
     1→0 (8)  1→2 (2)
     2→0 (5)  2→3 (1)
     3→0 (2)
     4→0 (1)   （4 へ入る辺はない）

          3            2
     0 -------> 1 -------> 2
     ^ |                   |
    2| |7                  | 1
     | v                   |
     3 <-------------------+

     4 --1--> 0
     （1→0: 8, 2→0: 5 は省略）
```

### 初期行列
```
      0    1    2    3    4
0     0    3  INF    7  INF
1     8    0    2  INF  INF
2     5  INF    0    1  INF
3     2  INF  INF    0  INF
4     1  INF  INF  INF    0
```

### k = 0（頂点 0 を経由してよい）
```
1→3: 1→0→3 = 8+7 = 15    2→1: 2→0→1 = 5+3 = 8
3→1: 3→0→1 = 2+3 = 5     4→1: 4→0→1 = 1+3 = 4    4→3: 4→0→3 = 1+7 = 8
```

### k = 1, 2, 3 と続けると…
```
k=1: 0→2 = 5,  3→2 = 7,  4→2 = 6
k=2: 0→3 = 6 (7→6),  1→0 = 7 (8→7),  1→3 = 3 (15→3),  4→3 = 7 (8→7)
k=3: 1→0 = 5 (7→5),  2→0 = 3 (5→3),  2→1 = 6 (8→6)
k=4: 4 へ入る辺がないので更新なし
```

### 最終結果
```
      0    1    2    3    4
0     0    3    5    6  INF
1     5    0    2    3  INF
2     3    6    0    1  INF
3     2    5    7    0  INF
4     1    4    6    7    0

Negative cycle: No
```
4 列目がすべて INF（どこからも 4 には行けない）なのがポイントです。

## コードの解説

### 本体（main.cpp:6-22）
```cpp
int n = dist.size();
for (int k = 0; k < n; ++k)              // 中継点（必ず一番外）
{
    for (int i = 0; i < n; ++i)          // 始点
    {
        for (int j = 0; j < n; ++j)      // 終点
        {
            if (dist[i][k] != INF && dist[k][j] != INF &&
                dist[i][k] + dist[k][j] < dist[i][j])
            {
                dist[i][j] = dist[i][k] + dist[k][j];  // i→k→j の方が短い
            }
        }
    }
}
```
- k を外に置くことで「0..k-1 を中継に使った最短距離」が k のループ開始時点で全ペア揃っている
- INF チェックがないと、負の辺があるとき `INF + (-5) < INF` で誤更新される

### 負閉路の判定（main.cpp:24-32）
```cpp
for (int i = 0; i < static_cast<int>(dist.size()); ++i)
{
    if (dist[i][i] < 0)      // 自分に戻るのに負 = 負閉路上にある
        return true;
}
return false;
```

### 初期化（main.cpp:36-50）
```cpp
std::vector<std::vector<int>> dist(n, std::vector<int>(n, INF));
for (int i = 0; i < n; ++i)
    dist[i][i] = 0;          // 自分自身への距離は 0
dist[0][1] = 3;              // 辺の重みを直接入れる
...
```
- 隣接行列がそのまま DP テーブルになる
- 同じペアに複数の辺がある問題では `std::min` で小さい方を入れる

### 出力（main.cpp:54-66）
- INF は `INF` と表示し、最後に負閉路の有無を出力

## 計算量
- **時間計算量**: O(V³)
- **空間計算量**: O(V²)
- V = 400 で 6.4 × 10⁷ 回程度。V が 10³ を超えると厳しい

## 最短経路アルゴリズムの使い分け
| | Dijkstra | Bellman-Ford | Floyd-Warshall |
|---|----------|--------------|----------------|
| 求めるもの | 単一始点 | 単一始点 | 全点対 |
| 負の辺 | ✕ | ◯ | ◯ |
| 負閉路の検出 | ✕ | ◯ | ◯（`dist[i][i] < 0`） |
| 計算量 | O((V+E) log V) | O(V × E) | O(V³) |
| 目安 | 非負の重みならまずこれ | 負の辺 / 辺数制限付き | V ≤ 400 程度で全点対 |

- 非負の重みで全点対が欲しく、V が大きい疎グラフなら「全頂点からダイクストラ」O(V (V+E) log V) の方が速い

## 特徴
- **超シンプル**: 三重ループ + 1つの if
- **全点対**: 1回の実行で任意のペアに O(1) で答えられる
- **負の辺に対応**: 負閉路の検出も可能

## 使いどころ
- 頂点数が小さい全点対最短経路
- 推移閉包（`reach[i][j] = reach[i][j] || (reach[i][k] && reach[k][j])`）
- 都市間の距離表を作る問題

## 注意点
- ループ順を i → j → k にすると誤り（よくあるバグ）
- INF を `INT_MAX` にすると足し算でオーバーフローする
- 無向グラフは `dist[u][v]` と `dist[v][u]` の両方に入れる
