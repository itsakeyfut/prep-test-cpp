# Bucket Sort - バケットソート

## 概要
バケットソートは、値の範囲をいくつかの**バケット（区間）**に分けて要素を振り分け、各バケットの中を個別にソートしてから順に連結するソートです。このコードは **[0, 1) の実数**を n 個のバケットに分け、各バケットを**挿入ソート**で並べます。データが一様に分布していれば平均 O(n) で動きます。

## 目的
- 「値を区間に振り分ける」という発想を身につける（ソート以外にも頻出）
- データの分布によって計算量が変わることを理解する
- 解ける問題の例: 164 Maximum Gap（鳩の巣原理 + バケット）、347 Top K Frequent Elements（頻度をバケットの添字にする）、451 Sort Characters By Frequency、220 Contains Duplicate III

## バケットソートの動き
```
入力: [0.78, 0.17, 0.39, 0.26, 0.72, 0.94, 0.21, 0.12, 0.23, 0.68]
n = 10 → バケット番号 = floor(x * 10)

【1. 振り分け】
B0: [ ]
B1: [0.17, 0.12]
B2: [0.26, 0.21, 0.23]
B3: [0.39]
B4: [ ]
B5: [ ]
B6: [0.68]
B7: [0.78, 0.72]
B8: [ ]
B9: [0.94]

【2. 各バケットを挿入ソート】
B1: [0.12, 0.17]
B2: [0.21, 0.23, 0.26]
B7: [0.72, 0.78]

【3. 順に連結】
[0.12, 0.17, 0.21, 0.23, 0.26, 0.39, 0.68, 0.72, 0.78, 0.94]
```
バケット同士は値の範囲が重ならないので、中身をソートして並べるだけで全体がソートされます。

## コードの解説

### 挿入ソート（main.cpp:6-19）
```cpp
void insertionSort(vector<double> &bucket)
{
    for (size_t i = 1; i < bucket.size(); ++i)
    {
        double key = bucket[i];
        size_t j = i;
        while (j > 0 && bucket[j - 1] > key)   // key より大きいものを右にずらす
        {
            bucket[j] = bucket[j - 1];
            --j;
        }
        bucket[j] = key;                       // 空いた場所に挿入
    }
}
```
- 1つのバケットには平均 O(1) 個しか入らないので、単純な挿入ソートで十分

### バケットソート本体（main.cpp:21-38）
```cpp
void bucketSort(vector<double> &nums)
{
    size_t n = nums.size();
    if (n == 0)
        return;

    vector<vector<double>> buckets(n);                       // n 個のバケット
    for (double x : nums)
        buckets[static_cast<size_t>(x * n)].push_back(x);    // 1. 振り分け

    size_t index = 0;
    for (auto &bucket : buckets)
    {
        insertionSort(bucket);                               // 2. 各バケットをソート
        for (double x : bucket)
            nums[index++] = x;                               // 3. 連結して書き戻す
    }
}
```
- [0, 1) の値に n を掛けると [0, n) になり、そのままバケット番号になる

## 計算量
- **時間計算量**:
  - 平均: O(n)（一様分布の場合、各バケットは平均 O(1) 個）
  - 最悪: O(n²)（すべてが1つのバケットに入り、挿入ソートが O(n²) になる場合）
- **空間計算量**: O(n)（バケット）

## 特徴
- **分布依存**: 一様分布で速く、偏ると遅い
- **安定ソート**: 振り分けも挿入ソートも順序を保つので安定
- **実数も扱える**: 計数ソート・基数ソートと違い、整数でなくてもよい

## 非比較ソートの比較
| ソート | 対象 | 時間計算量 | 前提 |
| ------ | ---- | ---------- | ---- |
| Counting Sort | 整数 | O(n + k) | 値の範囲 k が小さい |
| Radix Sort | 整数・固定長文字列 | O(d × (n + b)) | 桁数 d が小さい |
| Bucket Sort | 実数など | 平均 O(n) | 分布が一様 |

## 使いどころ
- 一様に分布した実数のソート
- 「頻度」や「値の範囲」でグループ分けする問題（347, 451）
- 最大ギャップ・近い値の検出（164, 220）

## 注意点
- [0, 1) 以外の範囲では `(x - minVal) / (maxVal - minVal + ε) * n` のように正規化する
- 値が 1.0 ちょうどだとバケット番号が n になり範囲外アクセスになる
- バケット内のソートは `std::sort` に置き換えると最悪 O(n log n) にできる
