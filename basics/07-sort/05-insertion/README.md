# Insertion Sort - 挿入ソート

## 概要
挿入ソートは、トランプの手札を整理するように、一つずつ正しい位置に挿入していくソートアルゴリズムです。ほぼソート済みのデータでは O(n) で終わるため、小さい配列では実際に高速で、`std::sort` の内部（イントロソート）でも小さい区間の仕上げに使われています。

## 目的
- 「ソート済み領域に1つずつ挿入する」という考え方を身につける
- 交換（swap）ではなく「一時保存して右にずらし、最後に1回書き込む」書き方を身につける
- 入力の並び（ほぼソート済みか、逆順か）で計算量が変わる**適応的**なアルゴリズムを理解する
- シェルソート（06-shell）、バケットソート（12-bucket）の内部処理の土台にする
- 解ける問題の例: 147 Insertion Sort List、88 Merge Sorted Array（後ろから挿入する発想）

## アルゴリズムの動き
左側を「ソート済み領域」、右側を「未ソート領域」として、未ソート領域から要素を取り出してソート済み領域の正しい位置に挿入します。

```
[3, 22, 19, 5] の場合

初期: [3] | 22, 19, 5        ← 最初の要素はソート済みとみなす

ステップ1: 22を挿入
          [3, 22] | 19, 5     ← 22は3より大きいのでそのまま

ステップ2: 19を挿入
          19を一時保存
          22を右へシフト
          [3, 19, 22] | 5     ← 19を正しい位置に挿入

ステップ3: 5を挿入
          5を一時保存
          22, 19を順に右へシフト（3は5より小さいので止まる）
          [3, 5, 19, 22]      ← 5を3の後ろに挿入
```

## コードの解説

### 主要な処理（main.cpp:12-23）
```cpp
for (size_t i{1}; i < size; ++i)
{
    auto tmp = nums[i];              // 挿入する要素を保存
    size_t j = i;

    while (j > 0 && nums[j - 1] > tmp)  // 挿入位置を探す
    {
        nums[j] = nums[j - 1];          // 要素を右にシフト
        j -= 1;
    }
    nums[j] = tmp;                   // 正しい位置に挿入
}
```

- `i`: 現在挿入しようとしている要素のインデックス
- `tmp`: 挿入する要素の値を一時保存
- `j`: 挿入位置を見つけるためのポインタ
- `while`ループ: `tmp`より大きい要素を右にシフトしながら挿入位置を探す
- `j > 0` を先に判定するので、`j == 0` のとき `nums[j - 1]` は評価されない（短絡評価）

## 計算量
- **時間計算量**:
  - 最良: O(n)（既にソート済みの場合、while が1回も回らない）
  - 平均: O(n²)
  - 最悪: O(n²)（逆順の場合）
  - より正確には O(n + 転倒数)（転倒数 = 順序が逆になっているペアの数）
- **空間計算量**: O(1)（追加のメモリ不要）

## 特徴
- **安定ソート**: 同じ値の順序が保たれる
- **適応的**: データが既にある程度ソート済みなら高速
- **オンライン**: データが順次到着する場合に有効
- **イン・プレース**: 追加の配列が不要
- **少ないデータに効率的**: 小規模データや部分的にソート済みのデータに向いている

## 使いどころ
- 小さいデータセット（数十要素程度）
- ほぼソート済みのデータ
- データが逐次的に到着する場合
- クイックソートやマージソートの内部処理（小さい部分配列に対して）
- 連結リストのソート（147。ずらす代わりにつなぎ替える）

## 注意点
- 比較を `>=` にすると同じ値も右にずらしてしまい、不安定になる
- 挿入位置の探索を二分探索にしても（二分挿入ソート）、ずらす処理が O(n) なので全体は O(n²) のまま
- `j` を `size_t` にしているので、`j >= 0` のような条件は常に真になる。`j > 0` と `nums[j - 1]` の組み合わせで書く

## 標準ライブラリ
挿入ソートそのものは標準ライブラリにはありません。`std::sort` は内部で小さい区間に挿入ソートを使っています。ソート済み配列への挿入は `std::upper_bound` + `vector::insert` で書けます。
