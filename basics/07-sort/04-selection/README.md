# Selection Sort - 選択ソート

## 概要
選択ソートは、未ソート部分から最小値を見つけて、未ソート部分の先頭と交換する操作を繰り返すソートアルゴリズムです。比較回数は常に n(n-1)/2 回ですが、交換は最大でも n-1 回しか行いません。

## 目的
- 配列を「ソート済み領域」と「未ソート領域」に分けて考える方法を身につける（挿入ソート・ヒープソートでも使う）
- 「最小値のインデックスを探す」ループを正確に書けるようにする
- 離れた要素を交換すると**不安定**になる理由を理解する
- ヒープソートが「最小値（最大値）探しをヒープで速くした選択ソート」であることにつなげる

## アルゴリズムの動き
配列を「ソート済み領域」と「未ソート領域」に分け、未ソート領域から最小値を選択してソート済み領域の末尾に追加します。

```
[3, 22, 19, 5] の場合

初期:      [] | 3, 22, 19, 5

ステップ1: 未ソート部分の最小値 3 を選択（既に先頭なので交換なし）
          [3] | 22, 19, 5

ステップ2: 未ソート部分の最小値 5 を選択、22 と交換
          [3, 5] | 19, 22

ステップ3: 未ソート部分の最小値 19 を選択（既に先頭なので交換なし）
          [3, 5, 19] | 22

ステップ4: 残り 22
          [3, 5, 19, 22]
```

## コードの解説

### 主要な処理（main.cpp:12-26）
```cpp
for (size_t i{0}; i < size; ++i)
{
    uint32_t min_idx = i;            // 最小値のインデックスを初期化

    for (size_t j = i + 1; j < size; ++j)  // 未ソート部分を探索
    {
        if (nums[j] < nums[min_idx])
        {
            min_idx = j;             // より小さい値を見つけたら更新
        }
    }

    if (i != min_idx)
        swap(nums[i], nums[min_idx]);  // 最小値を現在位置と交換
}
```

- 外側のループ（`i`）: ソート済み領域の境界
- `min_idx`: 未ソート部分での最小値のインデックス
- 内側のループ（`j`）: 未ソート部分から最小値を探索
- `swap`: 見つけた最小値を現在位置と交換
- `<` で比較しているので、同じ値が複数あるときは最初に見つけたものが選ばれる

## 計算量
- **時間計算量**:
  - 最良: O(n²)
  - 平均: O(n²)
  - 最悪: O(n²)
- **空間計算量**: O(1)（追加のメモリ不要）
- **交換回数**: 最大 n-1 回（O(n)）

## 特徴
- **不安定ソート**: 同じ値の順序が保たれない可能性がある
  - 例: `[3a, 3b, 1]` → 最小値 1 と先頭の 3a を交換 → `[1, 3b, 3a]`（3aと3bの順序が入れ替わる）
- **データに依存しない**: どんなデータでも必ずO(n²)の比較
- **交換回数が少ない**: 最大でもn-1回の交換しか行わない
- **イン・プレース**: 追加の配列が不要
- **シンプル**: 理解しやすい

## 使いどころ
- メモリ書き込みが高コストな環境（交換回数が少ないため）
- 小さいデータセット
- アルゴリズムの学習用
- 実用には向かない（より高速なアルゴリズムを使うべき）

## 他のソートとの比較
- **挿入ソート vs 選択ソート**:
  - 挿入ソート: データがほぼソート済みなら高速（最良O(n)）、安定
  - 選択ソート: どんなデータでもO(n²)だが、交換回数が少ない、不安定
- **ヒープソート vs 選択ソート**:
  - どちらも「残りから最大（最小）を選んで確定させる」
  - 最大値探しを線形探索 O(n) で行うのが選択ソート、ヒープで O(log n) にしたのがヒープソート

## 注意点
- `min_idx` が `uint32_t` なので、`size_t` の `j` を代入するときに暗黙の縮小変換が起きる。`size_t` に揃えるべき
- 外側のループは `i < size - 1` でも十分（最後の1要素は自動的に確定する）
- 安定版にしたい場合は、交換ではなく「最小値を取り出して間を右にずらす」必要があり、移動回数が増える

## 標準ライブラリ
選択ソートそのものは標準ライブラリにはありません。最小値の探索部分は `std::min_element`、交換は `std::iter_swap` で書き換えられます。
