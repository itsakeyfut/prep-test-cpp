# Bogo Sort - ボゴソート

## 概要
ボゴソートは、配列をランダムにシャッフルして、ソートされているかチェックするアルゴリズムです。最も非効率的なソートアルゴリズムの一つで、実用性はありませんが、「ソート済みかどうかの判定」と「乱数の正しい使い方」を学ぶには面白い例です。

## 目的
- 「ソート済みか判定する」O(n) の処理を書けるようにする（他のソートのテストにも使える）
- `std::random_device` / `std::mt19937` / `std::shuffle` の正しい使い方を身につける
- 計算量が階乗（n!）になると、どれだけ現実的でないかを体感する
- 「正しいが遅いアルゴリズム」と「速いアルゴリズム」の差を意識するきっかけにする

## 達成条件
- [ ] 何も見ずに main.cpp を5分以内に手書きできる
- [ ] 平均試行回数が約 n! 回になる理由を説明できる（n! 通りの並びのうち正解は1通り）
- [ ] 乱数生成器を `static` にする理由を説明できる（毎回シードを作り直さない）
- [ ] `std::is_sorted` で isSorted を置き換えられる
- [ ] 要素数を 5 → 10 → 11 と増やしたときの実行時間の変化を予想し、実際に確かめられる

## アルゴリズムの動き
```
[3, 1, 2] をソートする場合（並びは 3! = 6 通り）

1回目: シャッフル → [2, 3, 1] → ソートされていない
2回目: シャッフル → [1, 3, 2] → ソートされていない
3回目: シャッフル → [3, 2, 1] → ソートされていない
...
N回目: シャッフル → [1, 2, 3] → ソート完了！
```

運が良ければ1回で終わりますが、最悪の場合は永遠に終わりません。

## コードの解説

### ソート済みチェック（main.cpp:7-15）
```cpp
bool isSorted(const std::vector<int> &arr)
{
    for (size_t i{1}; i < arr.size(); ++i)
    {
        if (arr[i - 1] > arr[i])
            return false;  // 逆順があればソートされていない
    }
    return true;
}
```
- 配列を先頭から順にチェック
- 1つでも逆順があればfalse
- `i` を 1 から始めて `arr[i - 1]` と比べるので、空配列でも範囲外アクセスしない

### シャッフル（main.cpp:17-22）
```cpp
void shuffle(std::vector<int> &arr)
{
    static std::random_device rd;      // 乱数生成器の初期化
    static std::mt19937 g(rd());       // メルセンヌ・ツイスタ
    std::shuffle(arr.begin(), arr.end(), g);  // ランダムに並び替え
}
```
- `std::shuffle`で配列をランダムに並び替え
- `static`で乱数生成器を1回だけ初期化

### ボゴソート本体（main.cpp:24-34）
```cpp
void bogoSort(std::vector<int> &arr)
{
    int32_t attempts{0};

    while (!isSorted(arr))  // ソートされるまでループ
    {
        shuffle(arr);       // シャッフル
        attempts++;
    }
    std::cout << "Sorted after " << attempts << " shuffles." << std::endl;
}
```
- ソートされるまで無限にシャッフルを繰り返す
- 試行回数をカウントして表示

## 計算量
- **時間計算量**:
  - 平均: O(n × n!)（約 n! 回のシャッフル × 毎回 O(n) のチェック）
  - 最良: O(n)（最初からソート済み）
  - 最悪: 上限なし（理論上は終わらない可能性がある）
- **空間計算量**: O(1)

## 特徴
- **非決定的**: 実行のたびに試行回数が変わる
- **極めて遅い**: 要素数が増えると現実的な時間では終わらない
- **シンプル**: コードは非常に単純
- **不安定ソート**: 同じ値の順序はシャッフルで崩れる

## 使いどころ
- **実用性なし**: 実際のプログラムでは絶対に使わない
- アルゴリズムの学習（悪い例として）
- ジョークや面白プログラムの実装

## 注意点
- main.cpp の入力は10要素なので、平均 10! = 3,628,800 回のシャッフルが必要（数秒〜かかる）
- `attempts` は `int32_t` なので、要素数を13以上にするとオーバーフローの危険がある（13! ≈ 62億）
- `rand() % n` で自作シャッフルすると偏りが出る。`std::shuffle` を使う
- `std::random_shuffle` は C++17 で削除されているので使わない

## 参考データ
- 5要素のソート: 平均 5! = 120回のシャッフル
- 10要素のソート: 平均 10! = 3,628,800回のシャッフル
- 15要素のソート: 平均 15! ≈ 1.3兆回のシャッフル（現実的でない）

## 標準ライブラリ
ソート済み判定は `std::is_sorted`、シャッフルは `std::shuffle`（`<algorithm>`）、乱数は `<random>` が提供されています。
