# Shell Sort - シェルソート

## 概要
シェルソートは、挿入ソートの改良版です。最初は離れた要素同士（gap 間隔）で挿入ソートを行ってデータを大まかに整え、gap を徐々に小さくしていき、最後に gap = 1（通常の挿入ソート）で仕上げます。挿入ソートは「ほぼソート済み」なら速い、という性質を利用しています。

## 目的
- 挿入ソートの「1つ左」を「gap 個左」に一般化する発想を理解する
- 挿入ソートの弱点（要素が1つずつしか動かない）を、遠くへ一気に動かすことで解決する考え方を身につける
- gap 列の選び方で計算量が変わることを知る

## アルゴリズムの動き
```
[3, 22, 19, 5, 6, 83] の場合（size = 6 → gap = 3 → 1）

gap = 3（3つ離れた要素どうしで挿入ソート）:
  グループ: (3, 5)  (22, 6)  (19, 83)
  [3, 22, 19, 5, 6, 83]
           ↓ 22と6が逆順なので入れ替わる
  [3, 6, 19, 5, 22, 83]

gap = 1（通常の挿入ソート）:
  [3, 5, 6, 19, 22, 83]  ← ほぼ整列済みなので少ない移動で完了
```

gapを徐々に小さくすることで効率的にソートします。

## コードの解説

### gap（間隔）の設定（main.cpp:12）
```cpp
for (size_t gap = size / 2; gap > 0; gap /= 2)
```
- 最初のgapは配列サイズの半分
- 各反復でgapを半分にする（Shellの元の方法）
- gap = 1になるまで繰り返す

### gap間隔の挿入ソート（main.cpp:14-25）
```cpp
for (size_t i{gap}; i < size; ++i)
{
    int tmp = nums[i];  // 挿入する値を保存
    size_t j = i;

    while (j >= gap && nums[j - gap] > tmp)
    {
        nums[j] = nums[j - gap];  // gap分だけ離れた要素をシフト
        j -= gap;
    }
    nums[j] = tmp;  // 適切な位置に挿入
}
```
- gap間隔で挿入ソートを実行
- 通常の挿入ソートの「1つ左」が「gap個左」になっただけ
- gap = 1のとき、通常の挿入ソートと同じ
- `i` を1ずつ進めるので、gap 個のグループを交互に処理している

## なぜ速いのか

### 通常の挿入ソート
```
[5, 4, 3, 2, 1] → 1を先頭に持ってくるのに4回ずらす。全体で10回の移動
```

### シェルソート
```
gap = 2: グループ (5, 3, 1) と (4, 2) をそれぞれ挿入ソート
         [1, 2, 3, 4, 5]  ← 遠くへ一気に動くので、ここでほぼ整列
gap = 1: [1, 2, 3, 4, 5]  ← 移動なしで完了
```

大きなgapで大まかに整列させることで、最終的な挿入ソート（gap = 1）の移動回数が大幅に減ります。

## 計算量
- **時間計算量**:
  - 最良: O(n log n)（ソート済みの場合、各 gap で O(n)）
  - 平均: gap 列によるが、おおよそ O(n^1.25)〜O(n^1.5)
  - 最悪: O(n²)（このコードの `gap /= 2` の場合）。Knuth の列なら O(n^1.5)
- **空間計算量**: O(1)

## 特徴
- **高速**: O(n²) の単純なソートの中では最も速い
- **不安定ソート**: 離れた要素を動かすので、同じ値の順序が保たれない場合がある
- **イン・プレース**: 追加の配列が不要
- **実装が簡単**: 挿入ソートに gap のループを足すだけ

## gap列の選択
このコードでは`gap /= 2`（シェルの元の列）を使用していますが、他にも：
- **Knuthの列**: 1, 4, 13, 40, ...（h = 3h + 1）。実用上よく使われる
- **Hibbardの列**: 1, 3, 7, 15, ...（2^k - 1）。最悪 O(n^1.5)
- **Ciuraの列**: 1, 4, 10, 23, 57, 132, 301, 701。実験的に最速とされる

gap列の選択でパフォーマンスが大きく変わります。

## 使いどころ
- 中規模データのソート（数千〜数万要素）
- 再帰を使いたくない環境（クイックソートやマージソートはスタックを使う）
- 組み込みシステム（メモリが少ない環境）
- データがある程度整列済みの場合

## 注意点
- main.cpp:10 の `size_t gap = size / 2;` は、for 文の中で同名の `gap` を宣言し直しているので使われていない（シャドーイング）。削除してよい
- `tmp` が `int` 固定なので、テンプレート化するなら `auto` か `T` にする
- `gap /= 2` の列は gap が偶数ばかりになり、奇数位置と偶数位置が最後まで混ざらない入力で O(n²) になる

## 標準ライブラリ
シェルソートそのものは標準ライブラリにはありません。実際には `std::sort` を使います。
