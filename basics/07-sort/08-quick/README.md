# Quick Sort - クイックソート

## 概要
クイックソートは**分割統治法**を用いた高速なソートアルゴリズムです。ピボット（基準値）を選び、それより小さい要素と大きい要素に分割（partition）して、左右を再帰的にソートします。マージソートと違い「分割した時点でピボットの位置が決まる」ので結合処理が不要で、平均的には最も速い比較ソートの一つです。

## 目的
- partition（ピボットを基準に左右へ振り分ける）を正確に書けるようにする（単体でも頻出）
- ピボットの選び方で O(n log n) にも O(n²) にもなることを理解する
- partition を片側だけ再帰する **Quick Select**（k 番目の要素を平均 O(n) で求める）につなげる
- 解ける問題の例: 912 Sort an Array、215 Kth Largest Element in an Array（Quick Select）、75 Sort Colors（3-way partition）、973 K Closest Points to Origin

## アルゴリズムの動き
1. **ピボット選択**: 基準となる値を選ぶ（このコードでは最後の要素）
2. **分割**: ピボット以下の要素を左、大きい要素を右に配置
3. **再帰**: 左右の部分配列に対して同じ処理を繰り返す

```
[3, 22, 19, 5] の場合（ピボット = 最後の要素）

初期: [3, 22, 19, 5]  ピボット=5, i = -1

【分割】
j=0: 3 <= 5 → i=0, nums[0]とnums[0]を交換 → [3, 22, 19, 5]
j=1: 22 > 5 → 何もしない
j=2: 19 > 5 → 何もしない
最後に nums[i+1]=22 とピボットを交換 → [3, 5, 19, 22]
                                          ↑
                                   ピボット位置確定（index 1）

【再帰】
左: [3]      → 1要素なので完了
右: [19, 22] → ピボット=22で分割
              [19, 22] → 完了

結果: [3, 5, 19, 22]
```

## コードの解説

### 分割処理（main.cpp:6-22）
```cpp
int partition(vector<int> &nums, int low, int high)
{
    int pivot = nums[high];    // ピボット（最後の要素）
    int i = low - 1;           // ピボット以下の領域の右端

    for (size_t j = low; j < high; ++j)
    {
        if (nums[j] <= pivot)  // ピボット以下なら
        {
            ++i;
            swap(nums[i], nums[j]);  // 左側の領域に移動
        }
    }

    swap(nums[i + 1], nums[high]);  // ピボットを正しい位置に
    return i + 1;                   // ピボットの位置を返す
}
```
- **Lomuto partition** と呼ばれる方式
- ループ中は常に `[low, i]` がピボット以下、`[i+1, j)` がピボットより大きい
- 最後にピボットを境界 `i+1` に置くと、その位置は最終的なソート結果と一致する

### 再帰処理（main.cpp:24-32）
```cpp
void quickSort(vector<int> &nums, int low, int high)
{
    if (low < high)
    {
        int pi = partition(nums, low, high);  // 分割してピボット位置取得
        quickSort(nums, low, pi - 1);         // 左半分を再帰的にソート
        quickSort(nums, pi + 1, high);        // 右半分を再帰的にソート
    }
}
```
- 閉区間 `[low, high]` で書いている
- ピボット `pi` は確定済みなので、左右どちらにも含めない

### 呼び出し用のラッパー（main.cpp:34-38）
```cpp
void quickSort(vector<int> &nums)
{
    if (!nums.empty())
        quickSort(nums, 0, nums.size() - 1);
}
```
- 空配列で `nums.size() - 1` がアンダーフローしないようにチェックしている

## 計算量
- **時間計算量**:
  - 最良: O(n log n)（毎回ちょうど半分に分割される場合）
  - 平均: O(n log n)
  - 最悪: O(n²)（ソート済み・逆順・全要素が同じ値で、最後の要素をピボットにした場合）
- **空間計算量**: 平均 O(log n)、最悪 O(n)（再帰スタック）

## 特徴
- **不安定ソート**: 離れた要素を交換するので、同じ値の順序が保たれない可能性がある
- **平均的に最速**: キャッシュ効率が良く、実用的には最も高速なソートアルゴリズムの一つ
- **イン・プレース**: 追加の配列が不要（マージソートより省メモリ）
- **ピボット選択が重要**: 選び方で性能が変わる

## ピボット選択の改善
このコードでは最後の要素をピボットにしていますが、以下の改善方法があります：

1. **ランダム**: ランダムに選んで末尾と交換してから partition → 最悪ケースをほぼ回避
2. **3点の中央値**: 先頭・中央・末尾の3つの中央値 → バランスの良い分割
3. **3-way partition**: `< pivot` / `== pivot` / `> pivot` の3つに分ける → 同じ値が多い場合に有効

## 使いどころ
- 一般的なソート用途（最も広く使われる）
- 大量のデータ
- メモリが限られている場合
- 平均的なケースで最高の性能が欲しい場合
- k 番目に大きい/小さい要素を求める（Quick Select、平均 O(n)）

## 他のソートとの比較
- **クイックソート vs マージソート**:
  - クイックソート: 平均的に速い、省メモリ、最悪O(n²)、不安定
  - マージソート: 常にO(n log n)、安定、追加メモリが必要
- **クイックソート vs ヒープソート**:
  - クイックソート: 平均的に速いが、最悪O(n²)
  - ヒープソート: 常にO(n log n)だが、キャッシュ効率が悪く平均的にやや遅い

## 注意点
- LeetCode 912 には全要素が同じ値・ソート済みのテストがあり、末尾固定ピボットだと O(n²) で TLE になる
- 全要素が同じ値だと、ランダムピボットでも Lomuto partition は O(n²) になる（3-way partition で解決）
- `size_t j` と `int high` を比較しているので符号の警告が出る。`int` に揃えるとよい
- 小さい側を再帰・大きい側をループにすると、最悪でも再帰スタックは O(log n) に抑えられる

## 標準ライブラリ
C++では`std::sort`（イントロソート: クイックソート＋ヒープソート＋挿入ソート、最悪 O(n log n)）が標準で提供されています。partition は`std::partition`、Quick Select は`std::nth_element`（平均 O(n)）で使えます。
