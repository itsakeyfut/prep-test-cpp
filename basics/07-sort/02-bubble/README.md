# Bubble Sort - バブルソート

## 概要
バブルソートは最も基本的なソートアルゴリズムの一つです。隣り合う要素を比較して、順序が逆なら交換する操作を繰り返します。1回のパスで最大値が末尾まで移動するので、n 回のパスで全体がソートされます。

## 目的
- 「隣同士を比べて交換する」という最も素朴なソートを理解する
- 1パスごとに末尾の要素が確定する（ループ不変条件）という考え方を身につける
- O(n²) のアルゴリズムが、n が大きいとなぜ使えないのかを理解する
- 「交換が起きなければ終了」という早期終了の最適化を理解する（03-cocktail につながる）

## アルゴリズムの動き
大きい値が泡（bubble）のように後ろに浮き上がっていくイメージです。

```
[3, 22, 19, 5] の場合

パス1: 3と22比較 → そのまま
      22と19比較 → [3, 19, 22, 5]
      22と5比較  → [3, 19, 5, 22] ← 最大値が最後に確定

パス2: 3と19比較 → そのまま
      19と5比較  → [3, 5, 19, 22] ← 2番目に大きい値が確定

パス3: 3と5比較  → そのまま
      [3, 5, 19, 22] ← 完了
```

## コードの解説

### 主要な処理（main.cpp:11-20）
```cpp
for (size_t i{0}; i < size; ++i)
{
    for (size_t j{0}; j < size - 1 - i; ++j)
    {
        if (nums[j] > nums[j + 1])
        {
            swap(nums[j], nums[j + 1]);
        }
    }
}
```

- 外側のループ（`i`）: パスの回数（最大 n 回）
- 内側のループ（`j`）: 各パスでの比較回数
- `size - 1 - i`: 既に確定した要素（末尾の i 個）は比較不要なので範囲を縮める
- 隣り合う要素を比較し、大きい方を後ろに移動
- `>` で比較している（`>=` ではない）ので、同じ値は交換されず安定になる

## 計算量
- **時間計算量**:
  - 最良: O(n²)（この実装は早期終了がないので、ソート済みでも全比較）
  - 平均: O(n²)
  - 最悪: O(n²)（逆順の場合、交換回数も n(n-1)/2 回）
- **空間計算量**: O(1)（追加のメモリ不要）

## 特徴
- **安定ソート**: 同じ値の順序が保たれる
- **イン・プレース**: 追加の配列が不要
- **シンプル**: 理解しやすい
- **遅い**: 大量のデータには不向き

## 使いどころ
- アルゴリズムの学習用
- 非常に小さいデータ（10要素未満）
- 実用には向かない（より高速なアルゴリズムを使うべき）

## 注意点
- 空配列で `size - 1 - i` を計算すると `size_t` がアンダーフローするが、外側のループが0回なので実行されない
- 早期終了の最適化:
  ```cpp
  bool swapped = false;
  // 内側のループで交換したら swapped = true
  if (!swapped) break;  // 1度も交換がなければソート完了
  ```
- 小さい値が末尾にあると1パスに1つずつしか前に進まない（「タートル」問題。03-cocktail で改善）

## 標準ライブラリ
バブルソートそのものは標準ライブラリにはありません。実際には `std::sort`（不安定）や `std::stable_sort`（安定）を使います。
