# Radix Sort - 基数ソート

## 概要
基数ソートは、整数を**桁ごとに**ソートする非比較ソートです。このコードは **LSD（Least Significant Digit）方式**で、1の位 → 10の位 → 100の位…と下の桁から順に、**安定な計数ソート**を1桁ずつかけていきます。桁数を d とすると O(d × (n + 10)) で動きます。

## 目的
- 値の範囲が大きくて計数ソートが使えない場合でも、桁に分ければ線形時間でソートできることを理解する
- 「下の桁から安定ソートを重ねると全体がソートされる」理由（安定性の重要さ）を理解する
- 解ける問題の例: 164 Maximum Gap（O(n) が要求される）、912 Sort an Array（負の数はオフセット）、2343 Query Kth Smallest Trimmed Number

## 基数ソートの動き
```
入力: [170, 45, 75, 90, 802, 24, 2, 66]

【1の位でソート】 (exp = 1)
 17[0]  4[5]  7[5]  9[0]  80[2]  2[4]  [2]  6[6]
→ [170, 90, 802, 2, 24, 45, 75, 66]
   0    0    2   2   4   5   5   6

【10の位でソート】 (exp = 10)
 1[7]0  [9]0  8[0]2  [0]2  [2]4  [4]5  [7]5  [6]6
→ [802, 2, 24, 45, 66, 170, 75, 90]
   0    0  2   4   6   7    7   9

【100の位でソート】 (exp = 100)
 [8]02  [0]02  [0]24  [0]45  [0]66  [1]70  [0]75  [0]90
→ [2, 24, 45, 66, 75, 90, 170, 802]
   0  0   0   0   0   0   1    8

結果: [2, 24, 45, 66, 75, 90, 170, 802]
```
10の位で `170` と `75` はどちらも 7 ですが、1の位でソート済みの順（170 → 75）が保たれています。これが**安定性**が必要な理由です。

## コードの解説

### 1桁分の計数ソート（main.cpp:7-25）
```cpp
void countingSortByDigit(vector<int> &nums, int exp)
{
    vector<int> count(10, 0);                // 桁は 0〜9 の10種類

    for (int n : nums)
        ++count[(n / exp) % 10];             // その桁の数字を数える

    for (int i = 1; i < 10; ++i)
        count[i] += count[i - 1];            // 累積

    vector<int> output(nums.size());
    for (int i = static_cast<int>(nums.size()) - 1; i >= 0; --i)
    {
        int digit = (nums[i] / exp) % 10;
        output[--count[digit]] = nums[i];    // 後ろから配置して安定に
    }

    nums = output;
}
```
- 計数ソートの `count[n]` を `count[(n / exp) % 10]` に変えただけ

### 基数ソート本体（main.cpp:27-35）
```cpp
void radixSort(vector<int> &nums)
{
    if (nums.empty())
        return;

    int maxVal = *max_element(nums.begin(), nums.end());
    for (int exp = 1; maxVal / exp > 0; exp *= 10)   // 最大値の桁数分だけ繰り返す
        countingSortByDigit(nums, exp);
}
```
- `exp` は 1, 10, 100, ... と増え、最大値の桁を超えたら終了

## 計算量
- **時間計算量**: O(d × (n + b))（d = 最大値の桁数, b = 基数 10）
  - int の範囲なら d ≤ 10 なので実質 O(n)
- **空間計算量**: O(n + b)

## 特徴
- **非比較ソート**: 値の範囲が大きくても桁数が少なければ線形時間
- **安定ソート**: 各桁で安定な計数ソートを使うため
- **LSD と MSD**: 下の桁から（LSD）はループで書けて簡単。上の桁から（MSD）は再帰になり、文字列の辞書順ソートなどに使う

## 使いどころ
- 大量の整数（ID、電話番号、日付など桁数が固定のデータ）
- O(n) が要求される問題（164 Maximum Gap）
- 固定長文字列のソート

## 注意点
- 負の数はそのままでは扱えない（最小値を引いてオフセットする、または正負で分ける）
- `exp *= 10` は最大値が `INT_MAX` 付近だとオーバーフローするので、厳密には `long long` を使う
- 基数を 256 などにすると桁数が減って高速になる（ビット演算で桁を取り出せる）
