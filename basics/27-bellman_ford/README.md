# Bellman-Ford - ベルマンフォード法

## 概要
ベルマンフォード法は、**負の重みの辺があっても** 単一始点の最短距離を求められるアルゴリズムです。「すべての辺で緩和する」操作を V-1 回繰り返します。さらにもう1回緩和して更新が起きれば、始点から到達できる **負閉路（一周すると距離が減り続けるサイクル）** が存在すると判定できます。

## 目的
- ダイクストラが使えない「負の辺あり」のグラフで最短経路を求める
- 負閉路の検出（裁定取引の検出など）
- 「最大 K 本の辺で」という制約付き最短経路（LeetCode 787）は、ループ回数を K+1 に制限したベルマンフォードそのもの

## ベルマンフォード法の動き
サンプルグラフ（有向、負の辺あり。CLRS の例）：
```
辺:  0→1 (6)   0→2 (7)
     1→2 (8)   1→3 (5)   1→4 (-4)
     2→3 (-3)  2→4 (9)
     3→1 (-2)
     4→0 (2)   4→3 (7)

         6           5
    0 -------> 1 -------> 3
    |  ^       |          ^
   7|  | 2  -4 |          | -3
    v  |       v          |
    2  +------ 4          |
    |                     |
    +---------------------+
    （1→2: 8, 2→4: 9, 3→1: -2, 4→3: 7 は省略）
```

### 反復ごとの dist（辺は上の順で緩和）
```
初期:    [0, INF, INF, INF, INF]

1回目:   0→1: 1=6    0→2: 2=7    1→3: 3=11   1→4: 4=2
         2→3: 3=4 (11→4)         3→1: 1=2 (6→2)
         →  [0, 2, 7, 4, 2]

2回目:   1→4: 4=-2 (2→-2)
         →  [0, 2, 7, 4, -2]

3回目:   更新なし → 早期終了

最終チェック: どの辺でも更新できない → 負閉路なし
結果: 0=0 1=2 2=7 3=4 4=-2
```

### 負閉路の例（0→1 (1), 1→2 (-1), 2→1 (-1)）
```
1 → 2 → 1 を一周すると -2。回るほど距離が減る

初期:  [0, INF, INF]
1回目: [0, -1, 0]
2回目: [0, -3, -2]
チェック: 1→2 で -4 < -2 → まだ更新できる → 負閉路あり
```

## コードの解説

### 辺の構造体（main.cpp:7-12）
```cpp
struct Edge
{
    int from;
    int to;
    int weight;
};
```
- 隣接リストではなく **辺リスト** で持つのが定番（全辺を順に回すだけなので）

### 緩和の反復（main.cpp:14-31）
```cpp
dist.assign(n, INF);
dist[src] = 0;
for (int i = 0; i < n - 1; ++i)          // V-1 回
{
    bool updated = false;
    for (const auto &e : edges)          // 全辺を緩和
    {
        if (dist[e.from] != INF && dist[e.from] + e.weight < dist[e.to])
        {
            dist[e.to] = dist[e.from] + e.weight;
            updated = true;
        }
    }
    if (!updated)
        break;                           // 収束したら終了
}
```
- `dist[e.from] != INF` がないと、到達不能な頂点から `INF + 負の重み` で誤更新される

### 負閉路の検出（main.cpp:33-38）
```cpp
for (const auto &e : edges)
{
    if (dist[e.from] != INF && dist[e.from] + e.weight < dist[e.to])
        return false;                    // V 回目でも更新できる = 負閉路
}
return true;
```

### 実行と出力（main.cpp:41-55）
- `bellman_ford` が `false` なら `negative cycle detected`、そうでなければ各頂点の距離を出力

### main（main.cpp:57-68）
- 負の辺を含むグラフと、負閉路を含むグラフの2つを実行

## 計算量
- **時間計算量**: O(V × E)
- **空間計算量**: O(V)

## 最短経路アルゴリズムの使い分け
| | Dijkstra | Bellman-Ford | Floyd-Warshall |
|---|----------|--------------|----------------|
| 求めるもの | 単一始点 | 単一始点 | 全点対 |
| 負の辺 | ✕ | ◯ | ◯ |
| 負閉路の検出 | ✕ | ◯ | ◯（`dist[i][i] < 0`） |
| 計算量 | O((V+E) log V) | O(V × E) | O(V³) |
| 目安 | 非負の重みならまずこれ | 負の辺 / 辺数制限付き | V ≤ 400 程度で全点対 |

## 特徴
- **シンプル**: 二重ループだけで書ける
- **負の辺に対応**: ダイクストラにない強み
- **遅い**: 非負の重みならダイクストラを使う

## 使いどころ
- 負の重みを含むグラフの最短経路
- 負閉路の検出（為替の裁定取引など）
- 経由する辺の本数に上限がある最短経路

## 注意点
- 辺数制限付き（LeetCode 787）では、1回の反復内で更新した値を同じ反復で使わないよう、`dist` のコピー（前回の値）から緩和する
- 負閉路は「始点から到達できるもの」だけ検出される
