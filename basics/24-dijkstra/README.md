# Dijkstra - ダイクストラ法

## 概要
ダイクストラ法は、**辺の重みがすべて非負** のグラフで、1つの始点から全頂点への最短距離を求めるアルゴリズムです。「まだ確定していない頂点のうち距離が最小のもの」を優先度付きキュー（min-heap）で取り出し、そこから出る辺で距離を更新（緩和）していきます。`prev` 配列を持てば最短経路そのものも復元できます。

## 目的
- 重み付きグラフの単一始点最短経路の定番。BFS の「重み付き版」と考える
- 「最小コスト」「最小時間」「最小の労力」系の問題はほぼこれ
- 状態を (頂点, 追加情報) に拡張したダイクストラにも応用できる

## ダイクストラ法の動き
サンプルグラフ（有向、6 は孤立頂点）：
```
  0 --7--> 1 --15--> 3 --6--> 4
  |        |         ^        ^
  9        10        11       9
  v        v         |        |
  2 <------+         |        |
  +------------------+        |
  +--2--> 5 ------------------+

  0 --14--> 5（図では省略）     6（孤立）
```
辺の一覧で書くと：
```
0→1 (7)   0→2 (9)   0→5 (14)
1→2 (10)  1→3 (15)
2→3 (11)  2→5 (2)
3→4 (6)
5→4 (9)
6: 辺なし
```

### 処理の流れ（始点 0）
```
pq から取り出し   更新                                  pq の中身
(0, 0)           1=7, 2=9, 5=14                         (7,1) (9,2) (14,5)
(7, 1)           3=22                                   (9,2) (14,5) (22,3)
(9, 2)           3=20 (22→20), 5=11 (14→11)             (11,5) (14,5) (20,3) (22,3)
(11, 5)          4=20                                   (14,5) (20,3) (20,4) (22,3)
(14, 5)          古いのでスキップ (14 > dist[5]=11)
(20, 3)          4: 26 > 20 なので更新なし
(20, 4)          出る辺なし
(22, 3)          古いのでスキップ
```

### 結果
```
0 -> 0: dist=0  path=0
0 -> 1: dist=7  path=0 1
0 -> 2: dist=9  path=0 2
0 -> 3: dist=20 path=0 2 3
0 -> 4: dist=20 path=0 2 5 4
0 -> 5: dist=11 path=0 2 5
0 -> 6: unreachable
```

## コードの解説

### 定数と型（main.cpp:8-10）
```cpp
constexpr int INF = 1'000'000'000;                              // 到達不能
using Graph = std::vector<std::vector<std::pair<int, int>>>;   // adj[u] = {(v, w), ...}
```
- `INT_MAX` だと `INF + w` でオーバーフローするので 10⁹ 程度にする

### ダイクストラ本体（main.cpp:12-37）
```cpp
std::vector<int> dist(n, INF);
prev.assign(n, -1);
std::priority_queue<std::pair<int, int>,
                    std::vector<std::pair<int, int>>,
                    std::greater<>> pq;     // (距離, 頂点) の min-heap
dist[src] = 0;
pq.push({0, src});
while (!pq.empty())
{
    auto [d, u] = pq.top();
    pq.pop();
    if (d > dist[u])
        continue;                // 既にもっと短い距離で確定済み
    for (auto [v, w] : adj[u])
    {
        if (dist[u] + w < dist[v])   // 緩和
        {
            dist[v] = dist[u] + w;
            prev[v] = u;             // どこから来たかを記録
            pq.push({dist[v], v});
        }
    }
}
```
- `pair` は first（距離）で比較されるので、距離を first に置く
- 同じ頂点が複数回 pq に入る（decrease-key の代わり）。古いものは `d > dist[u]` で捨てる

### 経路復元（main.cpp:39-48）
```cpp
for (int v = target; v != -1; v = prev[v])
    path.push_back(v);                      // ゴールから始点へ逆にたどる
std::reverse(path.begin(), path.end());     // 始点→ゴールの順に直す
```

### main（main.cpp:50-79）
- 隣接リストを直接初期化し（main.cpp:52-57）、各頂点への距離と経路を出力
- `dist[v] == INF` の頂点は到達不能として経路復元しない

## 計算量
- **時間計算量**: O((V + E) log V)（二分ヒープ）
- **空間計算量**: O(V + E)

## 最短経路アルゴリズムの使い分け
| | Dijkstra | Bellman-Ford | Floyd-Warshall |
|---|----------|--------------|----------------|
| 求めるもの | 単一始点 | 単一始点 | 全点対 |
| 負の辺 | ✕ | ◯ | ◯ |
| 負閉路の検出 | ✕ | ◯ | ◯（`dist[i][i] < 0`） |
| 計算量 | O((V+E) log V) | O(V × E) | O(V³) |
| 目安 | 非負の重みならまずこれ | 負の辺 / 辺数制限付き | V ≤ 400 程度で全点対 |

- 重みなし（全部 1）なら BFS で十分。重みが 0 と 1 だけなら 0-1 BFS（deque）

## 特徴
- **貪欲法**: 取り出した時点でその頂点の最短距離が確定する
- **非負の重みが前提**: 負の辺があると「確定済み」が後から覆り、正しく動かない

## 使いどころ
- 道路網・ネットワークの最短経路
- グリッドで移動コストが異なる問題
- 「最大確率」「最小の最大値」など、比較関数を変えた変種

## 注意点
- min-heap にするのを忘れると max-heap になり、遅く・誤りやすくなる
- 距離が大きくなる問題では `long long` を使う
- 1 始まりの頂点番号に注意（`adj(n + 1)`）
