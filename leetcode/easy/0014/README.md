# 14. Longest Common Prefix：単語カードを「たてに」読む解き方

[Problem](https://leetcode.com/problems/longest-common-prefix/)

## どんな問題？

いくつかの単語があります。**ぜんぶの単語の「はじまり」で、同じになっている部分** のうち、いちばん長いものを答える問題です。

```
単語のならび (strs):  [ "flower", "flow", "flight" ]

  f l o w e r
  f l o w
  f l i g h t
  ───
  ここまで同じ → 答え "fl"
```

ぜんぶに共通する「はじまり」がないときは、からっぽ `""` を答えます。

```
  [ "dog", "racecar", "car" ]  →  1文字目から ちがう  →  答え ""
```

> 「はじまり」のことを、英語で **prefix（プレフィックス）** といいます。
> 「Common Prefix」は「みんなに共通するはじまり」という意味です。

---

## ふつうに考えると…（よこに読む「水平スキャン」のやり方）

まず、**1つ目の単語をまるごと「答えのこうほ」** にします。
そして、ほかの単語を1つずつ見て、**こうほがその単語のはじまりになっていなければ、こうほのうしろを1文字ずつけずって** いきます。

```
  こうほ: "flower"

  "flower" と くらべる → "flower" ではじまる ✅ そのまま
  "flow"   と くらべる → "flower" ではじまらない ❌
                          "flowe"  ではじまらない ❌  ← 1文字けずる
                          "flow"   ではじまる ✅       ← 1文字けずる
  "flight" と くらべる → "flow"   ではじまらない ❌
                          "flo"    ではじまらない ❌  ← 1文字けずる
                          "fl"     ではじまる ✅       ← 1文字けずる

  答え: "fl"
```

これでも答えは出ます。でも、**1つ目の単語が長くて、ほかの単語がみじかい** と、けずる作業がとても多くなります。
しかも、けずるたびに「はじまっているか」をまた最初から調べなおすので、むだがたくさんあります。

---

## かしこいやり方：単語カードを「たてに」読む（垂直スキャン）

### アイデア

単語を **カードに1文字ずつ書いて、たてにならべて** みましょう。

```
          1文字目  2文字目  3文字目  4文字目 ...
           ↓        ↓        ↓        ↓
  flower:  f        l        o        w   e   r
  flow:    f        l        o        w
  flight:  f        l        i        g   h   t
```

こうすると、**1列ずつ、たてに見ていけばいい** ことがわかります。

> 「この列は、ぜんぶ同じ文字かな？
> 同じなら、次の列へ。**1つでもちがったら、そこでおしまい**。」

ちがう文字が見つかった列の **1つ手前まで** が答えです。

### やることは、毎回たったの3ステップ

```
① 1つ目の単語の、この列の文字を「お手本」にする
② ほかの単語も、この列の文字がお手本と同じか調べる
      ├─ 単語がもう終わっている、または文字がちがう → 🎉 1つ手前の列までが答え
      └─ ぜんぶ同じ → ③へ
③ 次の列へ
```

---

## じっさいにやってみよう

`strs = ["flower", "flow", "flight"]` のとき。

### 1列目（pos = 0）

```
           ↓
  flower:  f  l  o  w  e  r
  flow:    f  l  o  w
  flight:  f  l  i  g  h  t

  お手本: f
  f, f, f → ぜんぶ同じ ✅ → 次の列へ
```

### 2列目（pos = 1）

```
              ↓
  flower:  f  l  o  w  e  r
  flow:    f  l  o  w
  flight:  f  l  i  g  h  t

  お手本: l
  l, l, l → ぜんぶ同じ ✅ → 次の列へ
```

### 3列目（pos = 2）

```
                 ↓
  flower:  f  l  o  w  e  r
  flow:    f  l  o  w
  flight:  f  l  i  g  h  t

  お手本: o
  o, o, i → 「flight」がちがう！ ❌ → ストップ

  1つ手前の列（2列目）までの "fl" が答え   🎉
```

**3列目まで見ただけ** で答えが出ました。`flower` のうしろの `w e r` は、一度も見ていません。

---

## コードとのたいおう

```cpp
std::string longestCommonPrefixVertex(const std::vector<std::string>& strs) {
    if (strs.empty()) return "";                         // 単語が1つもないなら、からっぽ

    const std::string& first = strs[0];                  // 1つ目の単語をお手本にする
    for (std::size_t pos = 0; pos < first.size(); ++pos) {   // 1列ずつ見ていく（pos が列の番号）
        const char expected = first[pos];                // ① この列のお手本の文字
        for (const std::string& str : strs) {            // ② ぜんぶの単語を調べる
            if (pos >= str.size() || str[pos] != expected)   //    単語が終わった？ 文字がちがう？
                return first.substr(0, pos);             //    → 1つ手前の列までが答え
        }
    }                                                    // ③ 次の列へ
    return first;                                        // 1つ目の単語をぜんぶ見終わった → それがまるごと答え
}
```

| コード | 意味 |
|---|---|
| `first` | 英語で「1つ目」。お手本にする単語 |
| `pos` | 英語の position（場所）。いま見ている列の番号（0 からはじまる） |
| `expected` | 英語で「期待される」。この列にあるはずのお手本の文字 |
| `pos >= str.size()` | その単語は、もうこの列まで文字がない（みじかくて終わっている） |
| `str[pos] != expected` | その単語のこの列の文字が、お手本とちがう |
| `first.substr(0, pos)` | お手本の単語の、0文字目から pos 文字ぶんを切りとる（= 1つ手前の列まで） |

### ふつうのやり方（水平スキャン）のコード

```cpp
std::string longestCommonPrefixHorizontal(const std::vector<std::string>& strs) {
    if (strs.empty()) return "";

    std::string prefix = strs[0];                        // 1つ目の単語を、答えのこうほにする
    for (const std::string& str : strs) {                // 単語を1つずつ見る
        while (!str.starts_with(prefix)) {               // こうほで はじまっていないあいだ
            prefix.pop_back();                           //   こうほのうしろを1文字けずる
            if (prefix.empty()) return "";               //   ぜんぶけずれたら、からっぽ
        }
    }
    return prefix;
}
```

| コード | 意味 |
|---|---|
| `str.starts_with(prefix)` | `str` が `prefix` ではじまっているか（C++20 からの機能） |
| `prefix.pop_back()` | `prefix` のうしろを1文字けずる |

## 気をつけポイント：「みじかい単語」で、カードの外をのぞかない

たてに読むやり方では、**お手本（1つ目の単語）より、みじかい単語** があるかもしれません。

`strs = ["flower", "flow"]` で考えてみましょう。

```
  5列目（pos = 4）

                       ↓
  flower:  f  l  o  w  e  r
  flow:    f  l  o  w  ？        ← 「flow」には 5文字目がない！
```

もし **「単語が終わっているか」を調べずに、いきなり文字をくらべたら** …

```
  flow の 5文字目を見る → そこにはカードがない！  ❌ のぞいてはいけない場所をのぞいてしまう
```

C++ では、**用意された場所の外をのぞくのは、とてもきけん** です。まちがった値が出たり、プログラムがこわれたりする原因になります。

だからコードでは、**先に「単語が終わっていないか」をチェック** しています。

```cpp
if (pos >= str.size() || str[pos] != expected)
//  ~~~~~~~~~~~~~~~~     ~~~~~~~~~~~~~~~~~~~~~
//  ① 先にこっちを調べる   ② ①が「いいえ」のときだけ、こっちを調べる
```

`||`（または）は **左から順に調べて、左が「はい」なら右は調べない** というきまりがあります。
単語が終わっていたら、右の「文字をくらべる」は実行されないので、**カードの外をのぞかずにすみます** ✅。

```
  5列目:  flow は 4文字しかない → pos >= str.size() が「はい」 → ストップ
  答え: "flow"   ✅
```

> 反対に、**お手本のほうがみじかい** ときは、お手本を見終わった時点で for 文が終わり、
> 最後の `return first;` でお手本がまるごと答えになります。（例: `["ab", "abc"]` → `"ab"`）

## どれくらい速くなるの？

`strs = ["flower", "flower", "flower", "a"]`（答えは `""`）で、文字をくらべる回数をくらべてみます。

```
  よこに読む（水平スキャン）:
    flower と flower をくらべる  →  6文字
    flower と flower をくらべる  →  6文字
    flower と flower をくらべる  →  6文字
    "a" で、flower → flowe → flow → flo → fl → f → からっぽ と けずりつづける
    → だいたい 25回 くらべる

  たてに読む（垂直スキャン）:
    1列目:  f, f, f, a  → 「a」がちがう！ ストップ
    → 4回 くらべるだけ
```

| やり方 | 見るところ | 上の例 | むずかしい言い方 |
|---|---|---|---|
| よこに読む（水平スキャン） | 1つ目の単語が長いと、むだにけずる | 約25回 | 時間 O(S)（S = 全部の文字数） |
| たてに読む（垂直スキャン） | **答えの長さ + 1列** だけ | 4回 | 時間 O(S)・空間 O(1) |

むずかしい言い方ではどちらも O(S) ですが、**たてに読むやり方は、ちがう文字を見つけたしゅんかんに止まれる** ので、むだがありません。
そのため、面接ではこちらのやり方がよく使われます。

> **「見る向きを変えると、かんたんになることがある」**
> よこに読むとむずかしい問題も、たてに読むとスッキリすることがあります。
> 表やカードにならべて、いろいろな向きからながめてみよう！
